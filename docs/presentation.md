# Presentation Slide Deck

Use this file to submit your team's presentation slide deck for the hackathon.

## Requirements

- The slide deck **must be exported as a PDF**.
- The submitted file **must be named `presentation.pdf`**.

## Submission

1. Export your slides as a PDF.
2. Rename the file to `presentation.pdf`.
3. Place the file in this `docs/` directory (replace this placeholder file or add
   it alongside).
4. Commit and push the file to your repository before the submission deadline.
